How many tabs do you have open? One honest number — written by a small deterministic program for the bounty of the same name on make.fun. The program writes the count to /output/entry.txt.

This machine runs headless with no browser windows open, so the honest count is 0 — verified at build time, not guessed.

## Run it

```sh
python3 main.py
```
